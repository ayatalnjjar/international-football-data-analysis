# International Football Data Analysis

## Project Overview
This project analyzes international football match results using SQL and Google BigQuery as part of my Data Science training.

## Tools
- SQL
- Google BigQuery
- GitHub

## Objectives
- Analyze international football match results.
- Evaluate Jordan's historical football performance.
- Compare team performance across different decades.
- Explore wins, losses, draws, and goals scored.
- Investigate data completeness and analytical limitations.

## SQL Skills Applied
- SELECT and WHERE
- GROUP BY and aggregate functions
- JOINs
- Views
- Filtering and calculated metrics
- Data validation

## Key Findings
The analysis explored Jordan's match history, performance trends across decades, and goals scored and conceded.

Specific results are documented in the SQL queries and their outputs.
